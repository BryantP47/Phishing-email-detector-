Paste an email's original source to check it for phishing warning signs. Everything runs in your browser; the email is never uploaded.

Email source

Checks run as you type. You can also drop an .eml file onto the box.

How do I get an email's original source?
  • Gmail: open the email, click ⋮ (More) next to Reply, choose Show original, then Copy to clipboard.
  • Outlook.com / new Outlook: open the email, click …, then View → View message source. Select all and copy.
  • Outlook for Windows (classic): double-click the email to open it, then File → Properties. The Internet headers box has headers only, so paste them and then the message text below them.
  • Apple Mail: select the email, then View → Message → Raw Source. Select all and copy.
  • Yahoo Mail: open the email, click … (More), then View raw message.

Pasting only the visible message text works too, but the sender checks need the full source.

Result

A warning sign is not proof, and a clean result is not a guarantee. Phishing sent from a real but hacked account can look clean. When in doubt, contact the sender through a channel you already trust, and never sign in through a link in the email.
